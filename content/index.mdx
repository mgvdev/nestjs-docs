# NestJS packages by mgvdev

Documentation for a growing set of open-source packages for [NestJS](https://nestjs.com).

## Packages

### [nest-boost](/nest-boost)

**Laravel Boost, for NestJS.** An MCP server, AI guidelines, and agent skills that teach
your coding agent how *your* NestJS application is actually wired — its real modules,
routes, and dependency-injection graph — and how to write idiomatic Nest code.

[Get started →](/nest-boost/getting-started) · [GitHub](https://github.com/mgvdev/nest-boost) · [npm](https://www.npmjs.com/package/@mgvdev/nest-boost)

### [nestjs-ai](/nestjs-ai)

A NestJS toolkit over the [Vercel AI SDK](https://ai-sdk.dev) (v7): DI-native agents,
tools, structured output, streaming, embeddings, RAG, multimodal, prompts, guardrails,
orchestration, MCP, and production features (cost, rate limiting, memory, evals).

[Get started →](/nestjs-ai/getting-started) · [GitHub](https://github.com/mgvdev/nestjs-ai) · [npm](https://www.npmjs.com/package/@mgvdev/nestjs-ai)

### [nestkit](/nestkit)

A modern, package-manager–agnostic **NestJS workspace engine**. Replaces the Nest CLI's
Webpack monorepo mode with a package-based project graph — SWC for transforms, tsc for
types. Works with npm, pnpm, Yarn and Bun; apps, libraries and Vite frontends in one
workspace.

[Get started →](/nestkit/getting-started) · [GitHub](https://github.com/mgvdev/nestkit)

### [nestjs-bun-adapter](/nestjs-bun-adapter)

A lightweight **Bun HTTP adapter for NestJS**. It replaces the default Express/Fastify
adapter with `Bun.serve()`, bringing native WebSocket support, file uploads, streaming,
sessions, rate limiting, compression, and built-in middlewares — all while staying inside
the Bun runtime.

[Get started →](/nestjs-bun-adapter) · [GitHub](https://github.com/mgvdev/nest-bun-http-adapter) · [npm](https://www.npmjs.com/package/@mgvdev/nestjs-bun-adapter)
